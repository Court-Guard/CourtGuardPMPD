# Anonymous Submission Bundle

This folder is a clean export of the PMPD-based CourtGuard workspace for a fresh anonymous repository.

Included:

- PMPD runtime code
- datasets used in the current study
- raw CourtGuard result files for GPT-OSS-20B and Ministral-3B
- PMPD stores used in the MLCommons adaptation study
- anonymous paper source

Excluded:

- ancillary application-layer directories outside the PMPD submission scope
- local virtual environments and caches
- competitor raw-result folders
- local secrets and API keys
- compiled LaTeX logs and PDFs
